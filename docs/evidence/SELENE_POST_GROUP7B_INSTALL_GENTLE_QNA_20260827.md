## Interpretation

The teaching lifecycle itself worked: concepts 267-272 are retained,
Chat-active, source-linked, and independently inspectable. This Q&A does not
show that Selene failed to learn them. It shows that ordinary Chat currently
fails to hand some user requests to the retained knowledge or verified math
owner, then allows generic completion and expression layers to release a
different answer.

The existing LLM-parity architecture is present, but several connective
contracts still fail together:

```text
literal-preserving input
  -> mixed dialogue acts
  -> subject + requested-role retrieval
  -> capable content owner
  -> correction-aware recomputation
  -> semantic proof of visible completion
  -> human conversational realization
```

This is a coordination repair, not a reason to add another teaching packet or
ask Selene to repeat the Q&A.
