## Outcome

Selene's existing reasoning and domain owners now return a consistent typed
result boundary: required semantic fields, source roles, an honest epistemic
state, and one terminal receipt. The work did not create a general-solver organ
or expose hidden reasoning. Core/Mind still coordinates, domain owners verify
their own claims, and NLO and Voice still own expression.

Prediction, hypothesis, and counterfactual results remain provisional.
Counterfactual reasoning declares the changed premise, preserves the remaining
premises, states its consequence and limits, and restores the actual state.
Task plans now identify the objective, concrete steps, dependencies,
constraints, fallback, and stopping condition rather than substituting a
generic reversibility template.

## Phase 5A — Reasoning Operations and Receipts

The typed operation boundary now includes explicit contracts for:

- causal explanation and method;
- comparison, choice, disagreement, and correction;
- prediction and hypothesis;
- counterfactual reasoning;
- task-specific planning; and
- summary and closure.

Completed, missing-input, unsupported, conflict, wrong, and changed-retry
results expose source-role, epistemic, and terminal receipts. Fluent expression
cannot strengthen evidence status. Failed attempts remain inside the active
problem, and the bounded retry coordinator changes the affected approach once
and then stops. None of these receipts creates Memory, retained knowledge, or
teaching state.

## Phase 5B — Independently Verified Mathematics

Verified Math now uses exact `Fraction` arithmetic for a bounded prerequisite-
ordered scope:

- unit conversions;
- explicit fraction operations and fraction-to-decimal conversion;
- ratio simplification and direct same-rate proportions;
- simple one-variable linear equations;
- rectangle area and perimeter;
- triangle area; and
- mean, median, and range from explicit lists.

Every supported result includes an independent verification receipt. The
implementation does not use `eval`. Unsupported symbolic or advanced work is
held rather than approximated or released through confident prose.

## Phase 5C — Research and Local-Code Boundaries

Source-backed research continues to require attributed supplied packets or an
explicitly enabled external Library path. It separates source statements from
Selene's inferences, exposes disagreement and missing evidence, and cannot
release an invented or provenance-free citation.

Ordinary Chat can reach local-code inspection through either attributed pasted
code or a fresh exact-file approval. Workspace reads require an attributable
speaker envelope plus a separate current-request approval whose exact paths
match the requested files. Authentication alone is not permission.

The inspector rejects directories, globs, traversal, sensitive paths, stale or
mismatched approval, duplicate file requests, execution, writes, and broad
scans. Its answer remains bounded to inspected file and line evidence.
