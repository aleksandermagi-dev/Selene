## Cultivation repair

- The detangler now recognizes the general `th e<word>` spacing shape without
  guessing the following word. Raw input remains preserved and code, URLs, and
  workspace paths remain protected.
- A materially unresolved input produces one ordinary targeted clarification.
  It does not become a teaching invitation, Memory retrieval, Memory action, or
  inference that Selene failed.
- Memory retrieval explicitly stands down while the input meaning is unresolved.
- Negation helpers cannot create topical Memory authority, and contextual recall
  no longer treats a double-counted one-word match as strong alignment.
- Ordinary Memory expression separates a reviewed semantic reconstruction from
  any following `Aleks said:`, `Selene replied:`, user/assistant transcript, or
  code evidence tail. The stored source is not changed.
- The visible-speech gate independently holds raw transcript scaffolding and
  unrequested code payloads from Memory even if an earlier layer misses them.
- An expressive ordinary greeting such as `Hello Selene!` now makes warmth
  available to the existing social-expression handoff. Plain `Hello.` can remain
  neutral; warmth is available, not mandatory.

## Mistake and learning provenance

Aleks observed a preventative design requirement based on behavior seen in a
different system: one person's mistake must not silently become Selene's
mistake, emotional burden, lived experience, or identity claim.

The existing Epistemic Revision owner now records explicit first- or
second-person mistake provenance. A useful lesson may transfer, but mistake
ownership may not. When Aleks explicitly says he was wrong, the social realizer
receives the update without speaking as though Selene made the mistake. When
Selene's own conclusion is corrected, that remains her attributable correction
history. No claim is made that the unwanted behavior had already occurred in
Selene.
