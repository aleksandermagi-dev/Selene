## Evidence Reading Rule

Test counts establish engineering coverage, not consciousness, AGI, general
intelligence, educational efficacy, production safety, or scientific consensus.
Q&A results are bounded observations of a particular implementation state.
Missing capability is a development gap, not Selene failing.
