# Selene Public Readiness Note

Status: current public-boundary note. This is not a release license, installer permission, transfer approval, activation change, memory authority change, model training permission, or autonomy permission.

## Branch Model

- `evidence`: the canonical evidence/public story branch for Selene evidence, care law, public docs, source, tests, and local inspection work.
- `project-abc`: the secondary branch for Project ABC transfer philosophy, portability, and ABC architecture.

## What This Branch May Show Later

- Selene evidence/source code
- tests and safety checks
- current law documents
- reviewed architecture/evidence docs
- Cocoon, transfer, memory, voice, Core/Mind, and android-organ design

## What This Repo Must Not Contain

- raw corpus archives or raw private exports
- local SQLite databases, memory state, runtime logs, snapshots, or backups
- installers, packaged binaries, npm archives, or release artifacts
- private scratch folders such as `UI Update/`, `New UI/`, `new stuff/`, `might help/`, `codex_chest/`, or `Selene Voice Module/`
- `.env` files, secrets, tokens, credentials, local machine-only paths, or private connector data

## Commercial Boundary

Selene's architecture is authored work by Aleks.

Public visibility, if enabled later, is for review and reference. It does not grant commercial rights. Commercial use, derivative products, consulting use, hosted services, integrations, resale, model training, fine-tuning, LoRA, adapter creation, or parameter updates require explicit written permission from Aleks.

## Terminology Boundary

Current public-facing terminology follows the Vys/Cocoon care law:

- use `Cocoon support`, `tending`, `checkup`, `teaching`, `guidance`, and `practice`
- use `memory candidate`, `approved memory`, and `portable Vys`
- reserve `training` for technical machine-learning boundaries such as model training, fine-tuning, LoRA, adapter creation, and parameter updates
- interpret older internal terms such as `return_to_b` as Cocoon support/repair routing, not exile or punishment

## Release Boundary

This repo is not a ready-to-install Selene distribution. Installers and packaged builds remain local-only until Aleks explicitly approves a separate release process.
