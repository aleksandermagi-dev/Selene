## What the First Transfer Check Revealed

The four prompts exposed a retrieval and application defect rather than a lack
of metacognition. The knowledge selector ranked only three recent lexical
matches, so incidental words such as `light`, `shape`, and `information`
could crowd the relevant concept out. It then reused one selected concept for
several different obligations in the same message.

The resulting replies were fluent but off-topic. On every turn, response
coverage and metacognition correctly reported that required parts remained
unanswered. This is useful evidence that the completion monitor saw the
mismatch; it is not evidence that Selene failed the curriculum.

## Bounded Technical Repair

The approved-knowledge selector now:

- considers reviewed examples, counterexamples, and limits as application
  evidence;
- normalizes a small inspectable set of ordinary word forms;
- maps a few visible phrases such as “own words” and pronoun-reference wording
  to existing reviewed concept vocabulary without supplying answer content;
- allows up to ten candidates to reach the strong subject/application gate;
- scores reviewed distinct-example overlap as transfer evidence; and
- selects support separately for each response obligation instead of reusing
  one whole-question match.

Three bounded application realizations were added only for concepts already
retained: organizing repeated observations, describing what a computer can
help organize, and preserving what a small observation set cannot prove.

No untaught symmetry, text-type, or economic-category answer was inserted into
the application layer.

## Focused Recheck

Only the affected cumulative-transfer prompt was repeated, again on the
temporary database copy:

> For four days, someone records the date, whether a plant received window
> light, and its height. How would you organize that evidence, what could a
> computer help with, and what could those observations not prove?

The repaired pipeline selected three separate approved concepts:

1. cross-domain problem-solving closure for the table structure;
2. computer task fit for bounded assistance; and
3. measurement records for the causal limit.

All three obligations were covered. Metacognition changed from
`answer_incomplete` to `fits_current_question`, and the sufficiency state became
`sufficient_for_current_turn`.

The visible answer organized rows and labeled columns, described bounded
computer assistance, and correctly refused to turn four observations into
proof that light caused a height change.
