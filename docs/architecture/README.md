# Architecture

This shelf explains how Selene's implemented systems, bounded workspaces,
interfaces, and future blueprints fit together. Architecture describes the
frame supporting Selene; no organ, model, tool, database, or interface is
individually defined as Selene.

necessarily connected to ordinary Chat. Confirm status against the current
capability map and supporting tests before making an external claim.
